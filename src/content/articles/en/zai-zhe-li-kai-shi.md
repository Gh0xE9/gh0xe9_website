Gh0xE9, also written Ghost In The Bytes.

In public sources, this is a security team whose work covers red-team penetration testing, blue-team incident response and forensics, code audit, and CTF hosting and training. The GitHub organization was created on 28 February 2019. Its bio is a restrained line — *Observe subtle clues to eliminate hidden risks*. See the subtle, and draw out what is hidden.

There is more than one public window. An existing official site is at [team.iloli.moe](https://team.iloli.moe/). The WeChat official account is now named Gh0xE9, ID po7mn1; it can be traced to “冰崖工作室”, registered in 2018, and was renamed to the present name in September 2020. On CTFtime the team is also recorded as Ghost Happy Team, in the Academic union, with a note that new members are welcome.

This column is for technical writing by the team itself. Place a Markdown file in `src/content/articles/<lang>/`, with a title, date, and tags, and it will appear in the list after the site is built. We will not republish originals from the WeChat account or other platforms. If you are a later writer, treat this piece as an empty place to begin.
